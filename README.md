# Phishing-Email-Simulator-
An interactive web application that helps users learn how to identify phishing emails through realistic email examples.

## Features

- Interactive phishing detection quiz
- Realistic email interface
- Company logos
- Score tracking
- Email progress indicator
- Instant feedback
- Explanation after every answer
- Final performance report
- Restart quiz option

## Technologies Used

- Python
- Flask
- HTML
- CSS

## How to Run

1. Clone the repository

git clone <repository-link>

2. Install Flask

pip install flask

3. Run

python app.py

4. Open

http://127.0.0.1:5000/
